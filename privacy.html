Privacy Policy

Last updated: 12 November 2026

MoneyPrinterTurbo is a personal tool used only by its owner, Mac Tucker, to upload videos to the Oyster World YouTube channel. This policy explains what Google user data it touches.

Data the app accesses

  • YouTube upload permission (youtube.upload): used only to upload videos the owner made, with the title, description, tags, privacy setting, and publish time the owner chose.
  • YouTube read-only permission (youtube.readonly): used only to read the signed-in channel's ID and name, so the tool can confirm it is uploading to the right channel.

How data is stored

The OAuth refresh token is stored in a local file on the owner's own computer. No Google user data is sent to any server run by this app, and the app has no server of its own.

Sharing

Google user data is not sold, shared, or transferred to anyone, and it is not used for advertising. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file also ends the app's access.
